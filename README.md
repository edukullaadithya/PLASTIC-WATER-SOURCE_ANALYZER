# Plastic Waste Source Analyzer

## 1. Project Overview

The **Plastic Waste Source Analyzer** is a Python-based project designed to analyze plastic waste according to its source and category. It processes waste records, cleans invalid data, calculates total waste, determines percentage contributions, and identifies yearly growth trends.

The project uses Python programming concepts such as lists, dictionaries, functions, file handling, and data analysis to understand plastic waste generation and support better waste management decisions.

## 2. Objectives

- Analyze plastic waste generated by different sources.
- Identify the major contributors to plastic waste.
- Categorize plastic waste and calculate percentage contributions.
- Clean and validate input data.
- Calculate yearly waste totals and growth rates.
- Generate charts to visualize waste distribution and trends.
- Recommend strategies for reducing plastic waste.

## 3. Technologies Used

- **Programming Language:** Python
- **CSV Module:** To read and process input data.
- **Collections Module:** To calculate waste totals efficiently.
- **Matplotlib:** To generate graphs and charts.

- `category_pie.png` — Pie chart showing the percentage of waste by category.
- `yearly_trend.png` — Line graph showing yearly waste trends by source.

The three PNG files are generated when the program runs successfully.

## 5. Features

### Data Cleaning
- Removes records with missing or non-numeric quantities.
- Removes negative waste quantities.
- Identifies and removes duplicate records.
- Standardizes source names.

### Data Analysis
- Calculates total plastic waste.
- Ranks waste sources by quantity.
- Calculates the percentage contribution of each source.
- Ranks plastic waste categories.
- Calculates yearly waste totals.
- Estimates compound annual growth rates (CAGR).

### Data Visualization
- Generates a bar chart for waste by source.
- Generates a pie chart for waste by category.
- Generates a line graph for yearly waste trends.

The project analyzes six plastic waste categories:

5. Cutlery & Straws
6. Containers & Others
